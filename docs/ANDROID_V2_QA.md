# Android V2 — проверка установщика

Проверяемый файл: `asterion. elf beauties teach me all about Machine Learning. V2.apk`.

SHA-256: `61dba97d022cb135938f78f1202138218b4ddeceb4edd6a94500df1d53aeb38a`.
Размер: 35 294 677 байт. Android package: `org.asterion.livingprotocol`,
versionName 2.1.0, versionCode 3. Данные программы: campaign SHA-256
`a5fc4aa1e90084659ee8c9c7010ab803d74173c99a8aaa6185c47705ce50be0f`.

## Среда и границы

Фактическая проверка выполнена на Android 15 / API 35, x86_64, System WebView
124.0.6367.219. Экран 1280×720, область CSS 854×480. Используется software
emulator с ранее проверенным исправлением TCG; подробности в
[EMULATOR_COMPATIBILITY.md](EMULATOR_COMPATIBILITY.md). APK и Android image
не содержат изменений, предназначенных специально для эмулятора.

В APK включены ARM64 и x86_64, но физический ARM64-телефон здесь не проверялся.
Время software emulation не является измерением производительности телефона.
Автоматическое исполнение эталонных решений проверяет работоспособность,
а не усвоение материала человеком.

## Выполненные проверки

`artifacts/android-v2-qa.json` относится к указанному точному хешу. Установленный
`base.apk` проверен по SHA-256. Пройден настоящий путь через диалог, подготовку,
редактор, проверку понимания, изменённый случай и завершение первого эпизода.
Открылся второй эпизод; обязательной боёвки нет. Счётчики `completed` и наград
тест не выставляет. Код введён через CDP, видимые кнопки нажаты через Android ADB.

- Настоящий CPython 3.12.15 / Chaquopy 17.2.0 выполнил все 40 программ на
  обычных и переносных данных: **80 исполнений, 245 проверочных случаев**.
- Во время проверки включён airplane mode, Wi-Fi/mobile data выключены;
  Android сообщил `Active default network: none`. Контрольная строка stdout
  появилась после нажатия настоящей кнопки исполнения.
- Синтаксическая ошибка и неверная заготовка отклонены.
- Бесконечный цикл прерван по лимиту 1,5 с; JavaScript heartbeat продолжал
  работать. Timeout и Stop сменили отдельный процесс Python
  `9207 → 9290 → 9307`; немедленные повторные исполнения прошли.
- Черновик, успешный результат и завершённый эпизод сохранились после
  force-stop и холодного запуска. Старый файл сохранения предыдущей редакции
  остался побайтно неизменным; V2 использует отдельный `files/novel-v2`.

Полный проход всех 100 эпизодов и всех страниц обучения выполняется отдельным
браузерным тестом. Фактический native-проход дополнительно пролистал 14 страниц
первого занятия. Воспроизводимый Android smoke теперь ограничивает этот
повтор тремя страницами и открывает редактор через видимую вкладку «Код»;
основное назначение native-проверки — интерпретатор, клавиатура и сохранения.

`artifacts/android-v2-keyboard.json` содержит два настоящих цикла экранной
клавиатуры. ADB-нажатие сфокусировало textarea; Android Back скрыл IME.
Размер области менялся **480 → 180 → 480 CSS-пикселей** без двойного уменьшения.
Видны 130 CSS-пикселей редактора. После прокрутки кнопки исполнения, Stop и
закрытия находятся внутри области и не перекрыты клавиатурой. Снимки
`android-v2-keyboard.png` и `android-v2-keyboard-controls.png` просмотрены.

`artifacts/android-signature.json` подтверждает подпись APK и побайтовое
совпадение всех упакованных web-assets с исходниками. Приватного signing key
в APK нет; `assets/chaquopy/cacert.pem` является публичным набором CA runtime.

## Экспорт, импорт и восстановление

`artifacts/android-v2-storage.json` завершён с `passed: true` на том же
SHA-256 APK. Настоящий Android DocumentsUI создал экспортированный JSON
размером 3622 байта; контрольная сумма payload проверена. Файлы с неверной
контрольной суммой и с другой редакцией игры выбраны через системный диалог
и отклонены приложением: действующий payload в обоих случаях остался
побайтно неизменным. Корректный импорт восстановил контрольный маркер и
черновик; результат сохранился после force-stop и нового запуска.

После намеренного повреждения основного файла только в тестовом V2-профиле
приложение показало восстановление и заблокировало автоматическую перезапись.
Нажатие настоящей кнопки восстановления вернуло рабочую резервную копию,
сохранило повреждённый файл отдельно и выдержало ещё один force-stop/запуск.
Старое сохранение предыдущей редакции осталось побайтно неизменным.

Этот сценарий выполнен с продолжением от уже подтверждённого экспорта,
а не одним непрерывным запуском скрипта. В тестовом управлении исправлены
два промаха: использование старого XML после неудачного UIAutomator dump
и нажатие подписи файла, перекрытой системной панелью навигации. Экспорт
завершён ADB-нажатием видимой кнопки SAVE по свежему дереву; затем тест
повторно проверил файл и продолжил импорт и восстановление. Файлы выбирались
нажатием видимой области карточки в DocumentsUI. Это отмечено в поле
`exportContinuation` отчёта. Код игры и установщик во время исправления
тестового управления не менялись.

## Воспроизведение

Нужны установленный APK, запущенный тестовый эмулятор `emulator-5554`, ADB и
Python с пакетом `websockets`. Команды из корня проекта:

```sh
python tests/android_v2_qa.py
python tests/android_v2_ime.py
python tests/android_v2_storage.py
```

Для независимого первого прохода переменная `ASTERION_QA_RESET_PROFILE=1`
перемещает только V2-профиль тестового эмулятора в сохранённую копию с меткой
времени. Старый профиль не удаляется. Использовать это следует на тестовом
устройстве. Утилита холодного запуска очищает Android task, включая оставшийся
DocumentsUI после прерванного теста, но не стирает данные приложения.

# Мобильная новелла V2

**asterion. elf beauties teach me all about Machine Learning. V2** — отдельная романтическая учебная история в компании «Астерион». Сто эпизодов объединены в десять глав; в сорока эпизодах пользователь пишет и запускает настоящий Python. Ирис, Эйла, Мира и Селена — взрослые исследовательницы со своими интересами и четырьмя личными сюжетными ветками.

Восемь оригинальных иллюстрированных локаций различаются архитектурой: двор, архив, лунные мосты, обсерватория, оранжерея, лаборатория, воздушная станция и сад совета. Прозрачные портреты накладываются на сцены. Между занятиями доступна необязательная прогулка по изображённому саду; прохождение не зависит от боя или нажатий на скорость.

## Учебный маршрут

Встреча → объяснение с раскрываемыми предпосылками → пошаговый разобранный пример → конкретная практика → другой случай → собственный вывод. Для эпизода с Python есть отдельная подготовка ровно к данной программе: вход/выход, нужный синтаксис, методы и пример исполнения. Во время работы весь разбор можно открыть рядом с редактором, не теряя исходник.

Программа проверяется на обычных и дополнительных входах. Редактирование снимает обе отметки проверки; следующая попытка начинается с основной проверки. Ошибки и реальные результаты видны в журнале. После остановки или ухода приложения в фон исходник сохраняется, среда восстанавливается при следующем запуске. Подсказка и раскрытый эталон сохраняют честную отметку «с помощью». Свободный ответ предназначен для самопроверки и не оценивается по совпадению слов.

## Встречи и галерея

После каждого пятого эпизода возникает личная встреча с тремя репликами. Реплики сохраняются и меняют отношения; ошибки в обучении близость не уменьшают. В галерее есть четыре профиля, воспоминания о двадцати встречах и четыре необязательные особые истории. Особая история открывается после необходимого количества эпизодов и минимум двух встреч с персонажем. Повторное чтение не начисляет близость снова. Можно пройти все четыре ветки.

## Управление и сохранение

На сенсорном экране — кнопки, прокрутка текста и необязательный джойстик. На компьютере — мышь, WASD/стрелки для прогулки, E/Enter для встречи, Escape для паузы. В редакторе Tab вставляет четыре пробела, Ctrl/⌘+Enter запускает код; экранные кнопки помогают ввести отступы и скобки. Android Back открывает паузу.

Пауза позволяет продолжить, сохранить и выйти, экспортировать или импортировать сохранение. Новая редакция имеет `campaignEdition: elf-beauties-v2`; браузер использует `asterion.novel.v2`, Android — каталог `novel-v2`. Старые файлы автоматически не переносятся и не стираются. Импорт другой редакции отклоняется до записи. При повреждении основной копии предлагается восстановить предыдущую рабочую копию.

## Проверка

Актуальные проверки интерфейса:

- `python3 tests/browser_novel_ui.py` — настоящие ошибки Python, обе проверки программы, остановка/пауза, черновик и справочник, импорт другой редакции, восстановление копии, четыре размера окна.
- `python3 tests/browser_novel_route.py` — сто эпизодов через интерфейс, двести вопросов, восемьдесят реальных запусков Python, двадцать встреч, четыре ветки, повтор воспоминаний и восстановление после перезапуска. Состояние завершения не подставляется: используются известные проверочные ответы и эталонные программы.

Отчёты: `artifacts/v2-browser-ui.json` и `artifacts/v2-browser-route.json`. Они содержат контрольные суммы `campaign.json` и `app.js`. Финальный route требует `curriculumFinal: true`; режим `ALLOW_DRAFT_CURRICULUM=1` предназначен только для ранней проверки интерфейса до готовности учебных данных. Браузерные проверки запрещают внешние запросы. Эти тесты подтверждают работоспособность маршрута, но не измеряют обучение человека; проверка размеров браузерного окна не заменяет отдельную проверку Android IME на эмуляторе.
